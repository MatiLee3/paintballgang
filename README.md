Paintball Gang

Official one-page website for Paintball Gang — a paintball venue located on the grounds of a former military unit in Lisewo, near Gniewino, Poland.

Tech Stack
HTML5
Custom CSS (no frameworks, no build step)
Vanilla JavaScript
Lucide icons (self-hosted, no CDN)

No dependencies, no package manager, no build process — just static files.

Running Locally

Open index.html directly in a browser, or use a local server for the most accurate preview (e.g. VS Code's Live Server extension).

Deployment

This site is fully static and can be hosted anywhere — GitHub Pages, traditional hosting via FTP, etc. No server-side code or database required.
